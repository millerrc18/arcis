# Domain Preset: General

## Description

Catch-all default domain for queries that do not fit neatly into a specialized category. Covers broad knowledge topics including technology, science, history, culture, business, and any other subject matter. This preset applies balanced heuristics without strong bias toward any particular field.

## Preferred Sources

1. **Wikipedia** — Starting point for orientation and citation trails
2. **Official documentation** — Product docs, government sites, institutional pages
3. **Stack Overflow / Stack Exchange** — Technical Q&A across many domains
4. **Google Scholar** — Academic papers when depth warrants it
5. **Reputable news outlets** — Reuters, AP, BBC, NYT for current events context
6. **Encyclopedia Britannica** — Verified reference material
7. **Domain-specific official sites** — Whatever authority governs the topic at hand

## Lateral Search Strategy

Pull from whatever domain seems most relevant to the query. General research benefits from opportunistic cross-pollination:

- If the query touches on data or statistics, pull methods from **statistics / data science**
- If the query involves human behavior, pull from **psychology / behavioral economics**
- If the query involves systems or processes, pull from **engineering / systems thinking**
- If the query involves history or trends, pull from **historiography / trend analysis**

The general domain is unique in that lateral search is entirely query-dependent rather than pre-defined.

## Temporal Emphasis

Neutral temporal weighting. Neither strongly foundational nor strongly current.

- **Half-life**: 3 years
- **Guidance**: Weight sources from the last 3 years more heavily, but do not discard older material if it remains the best available reference. Foundational works (textbooks, seminal papers) retain value regardless of age.

## Output Template Tweaks

No special sections added to the standard report template. The general domain uses the dialectical template as-is.

## Example Queries

1. "What are the most effective study techniques according to cognitive science?"
2. "Compare pros and cons of remote work for knowledge workers"
3. "History and current state of nuclear fusion energy research"
