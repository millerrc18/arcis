## Implementation summary

### Part A — VIX enrichment (#535)

| Change | File | Net lines |
|---|---|---|
| New helper `lookup_vix_at_entry` | `src/platform/vix_lookup.py` | +73 (new file) |
| Import + dataclass field + helper call | `src/platform/backtest_engine.py` | +5 |
| New tests | `tests/platform/rigor/test_vix_enrichment.py` | +358 (new file) |

VIX source = yfinance `^VIX` via existing `fetch_cached_ohlcv`. Helper returns the most-recent Close on or before `entry_iso`, with a 7-day lookback window so non-trading-day entries (Monday after Friday holiday + weekend, etc.) still hit a bar. Returns None on cache miss / empty frame / no eligible bar — graceful degradation, never raises.

`BacktestTrade.vix_at_entry: float | None = None` defaulted so legacy callers stay backwards-compatible. Wired via single call inside `_build_trade()` — both `_run_scheduled` and `_run_event_driven` paths benefit.
