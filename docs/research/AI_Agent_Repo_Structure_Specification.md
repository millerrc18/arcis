# AI-Agent Repo Structure Specification

> **Goal:** CC and Codex can make improvements with minimal context loading.
> Sprint prompts shrink from 600 lines to ~100 lines because the repo is self-documenting.

---

## Principle: The repo IS the context

Instead of explaining the codebase in every sprint prompt, the codebase explains itself.
CC/Codex reads 2 files to understand everything:

1. **AGENTS.md** — the map (what exists, where it lives, how it connects)
2. **The sprint prompt** — the tasks (just a short task list, no system overview)

Everything else is discoverable from those two entry points.

## Dependency Hierarchy (top to bottom)

```
Layer 4: Orchestration — watch.py, main.py (can import anything below)
Layer 3: Services — scan_service.py, council/engine.py (can import Layer 2)
Layer 2: Domain — executor.py, governor.py, traffic_light.py, features/* (can import Layer 1)
Layer 1: Infrastructure — alpaca_adapter.py, telegram.py, render_sync.py, llm/* (no domain imports)
```

**Rule:** Imports only go DOWN. A Layer 1 module never imports from Layer 2+.

## Patterns (how we do things here)

### API Endpoint Pattern
```python
# In src/api/cloud_routes/{group}.py
@router.get("/api/{resource}")
async def get_resource(db=Depends(get_db)):
    """One-line description."""
    # Query, compute, return dict
```
Then add to frontend/src/api.js:
```javascript
getResource: () => fetchApi('/resource'),
```

### DB Table Pattern
1. Add CREATE TABLE to scripts/create_missing_tables.py
2. Add CREATE TABLE to scripts/render_migrate.py (Postgres syntax)
3. Add sync config to src/sync/render_sync.py
4. If cloud→local needed, add to pull_commands() (Sprint 4C)

### Test Pattern
```python
"""Tests for {module} — {what it covers}."""
import pytest
from src.{module} import {functions}

@pytest.fixture
def db(tmp_path):
    """Isolated DB with test data."""
    ...

class TestFeatureName:
    def test_happy_path(self, db): ...
    def test_edge_case(self, db): ...
    def test_error_handling(self, db): ...
```

### Module Docstring Pattern (MANDATORY for every .py file in src/)
```python
"""Module name — one-line description.

Called by: caller1.py, caller2.py
Calls: callee1.py, callee2.py
Owns tables: table_name1, table_name2
Config keys: section.key1, section.key2
Tests: tests/test_this_module.py
"""
```

## Change 2: Standardize ALL module docstrings

Every .py file in src/ gets the structured header:

```python
"""Module name — one-line description.

Called by: list of callers
Calls: list of callees
Owns tables: list of DB tables this module creates/writes
Config keys: list of settings.yaml keys this module reads
Tests: tests/test_file.py
"""
```

This is machine-parseable. A script can build the dependency graph from docstrings alone.
CC/Codex can `grep "Called by:"` to understand the call graph without reading implementations.

**Enforcement:** Add a test that verifies every .py in src/ has the 5-field docstring header.

## Change 4: Automated guardrails as tests

Add to the test suite (run on every sprint):

### test_repo_structure.py
```python
"""Repository structure enforcement — prevents drift."""
import ast
import re
from pathlib import Path

def test_no_file_over_400_lines():
    for p in Path("src").rglob("*.py"):
        lines = len(p.read_text().splitlines())
        assert lines <= 400, f"{p} is {lines} lines (max 400)"

def test_no_function_over_60_lines():
    for p in Path("src").rglob("*.py"):
        tree = ast.parse(p.read_text())
        for node in ast.walk(tree):
            if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef)):
                length = node.end_lineno - node.lineno
                assert length <= 60, f"{p}:{node.name} is {length} lines (max 60)"

def test_all_modules_have_standard_docstring():
    required_fields = ["Called by:", "Calls:", "Owns tables:", "Config keys:", "Tests:"]
    for p in Path("src").rglob("*.py"):
        if p.name == "__init__.py":
            continue
        content = p.read_text()
        # Check for module-level docstring
        tree = ast.parse(content)
        if not (tree.body and isinstance(tree.body[0], ast.Expr) and isinstance(tree.body[0].value, ast.Constant)):
            assert False, f"{p} missing module docstring"
        docstring = tree.body[0].value.value
        for field in required_fields:
            assert field in docstring, f"{p} docstring missing '{field}'"

def test_no_upward_imports():
    """Layer 1 modules should not import from Layer 2+."""
    layer1 = {"alpaca_adapter", "telegram", "render_sync", "email_notifier"}
    layer2_plus = {"scan_service", "governor", "executor", "watch", "engine"}
    # Parse imports in layer1 files, verify none reference layer2_plus
    for p in Path("src").rglob("*.py"):
        if p.stem not in layer1:
            continue
        content = p.read_text()
        for mod in layer2_plus:
            assert f"from src.services.{mod}" not in content, f"{p} imports Layer 2+ module {mod}"
            assert f"from src.scheduler.{mod}" not in content, f"{p} imports Layer 2+ module {mod}"

def test_every_api_endpoint_has_frontend_method():
    """Every cloud API route should have a corresponding method in api.js."""
    api_routes = set()
    for p in Path("src/api/cloud_routes").glob("*.py"):
        for line in p.read_text().splitlines():
            m = re.search(r'@router\.(get|post)\("(/api/[^"]+)"', line)
            if m:
                api_routes.add(m.group(2))
    
    api_js = Path("frontend/src/api.js").read_text()
    for route in api_routes:
        # Check the path fragment exists in api.js
        path_fragment = route.replace("/api/", "/")
        assert path_fragment in api_js, f"API route {route} has no frontend method in api.js"

def test_every_new_table_in_render_migrate():
    """Every CREATE TABLE in src/ should also appear in render_migrate.py."""
    migrate = Path("scripts/render_migrate.py").read_text().lower()
    for p in Path("src").rglob("*.py"):
        for line in p.read_text().splitlines():
            m = re.search(r'CREATE TABLE IF NOT EXISTS (\w+)', line)
            if m:
                table = m.group(1).lower()
                assert table in migrate, f"Table '{table}' in {p} not in render_migrate.py"
```

These tests run automatically. If CC creates a new API endpoint without adding it to api.js, the test fails. If CC creates a module without the docstring header, the test fails. The guardrails are self-enforcing.

## Change 5: conventions.md — the pattern library

A single file that CC/Codex reads alongside AGENTS.md:

```markdown
# conventions.md — How We Build Things

## Adding a feature
1. Create src/{domain}/feature_name.py with standard docstring header
2. Write tests in tests/test_feature_name.py (≥5 tests)
3. Wire into caller (usually scan_service or watch.py)
4. If it needs an API: add route to cloud_routes/{group}.py + method to api.js
5. If it needs a DB table: add to create_missing_tables.py + render_migrate.py + render_sync.py
6. Update AGENTS.md module registry

## Adding a dashboard page
1. Create frontend/src/pages/PageName.jsx
2. Add route in App.jsx
3. Add nav item in Layout.jsx
4. Add API methods in api.js
5. Update AGENTS.md dashboard page count

## CSS
- Use var(--arcis-*) variables for all colors
- Financial data: className="financial-data" (JetBrains Mono, tabular-nums)
- P&L always includes ▲/▼ arrows for accessibility
- Mobile-first: single column, no horizontal scroll

## Testing
- ≥5 tests per module
- Use pytest fixtures with tmp_path for DB isolation
- Test happy path, edge cases, error handling
- Never mock what you can create (prefer real SQLite over mocked queries)
```
